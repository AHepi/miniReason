# Configuration lessons

Source-code inspection shows that Mini stages select their ports explicitly, and input windows determine which cycles they can read. A port declaration alone does not make content visible. Inspect the actual rendered request before interpreting a failed criticism or repair.

Mini defaults to separate body and commitment calls. Original experiments declare `commitment_call: single` unless a test deliberately changes it; this makes call accounting explicit, but its effect on reasoning remains an experimental question.

E005 exposed both inline problem (8192 characters) and kind-instruction (4000 characters) limits. Full model-proposed languages must travel as source-backed artifacts where supported, not be inserted into instruction fields. The evidence legend is an excerpt and cannot serve as the full language. A fixture that proves port visibility on short strings does not establish that the real material fits. Compile actual source-backed manifests before constructing any paid provider.

The inquiry preparation findings show that the complete queued object needs its own verified identity, including added metadata, if it is to be selected unchanged later. Validate the relation between signed fields and actual text, and between the selected issue and activation, rather than checking only an outer digest. Provider settings and unavailable resource observations are part of the same comparison boundary; a missing counter cannot be replaced with a claim of zero cost. See INQ-PREP-001 through INQ-PREP-004.
