### R003 R3-A2 prose-seat custody lesson

A prose locator needs an explicit grain and source snapshot. A working-position claim, result commitment, whole current derivation, and indexed derivation paragraph are different public fields even when they express related content. Diagnose which field the checker actually targets before calling an exact-quote failure fabrication or a correct quote. Show the candidate target in bounded repairs and permit an explicit real index without accepting a mismatched nonempty quotation. Likewise, evaluate a decomposed commitment against its declared step and dependencies; absence of work assigned to later steps does not by itself refute that commitment. A syntactically valid decision/relation with a refuter is still a criticizable declaration, not mechanical proof of semantic refutability.

Inspect actual rendered context ports as well as prompt wording: a seat cannot inspect a stated refuter if the structured field carrying it is omitted. Replay immutable outputs through the full parser under both contract versions, reproducing the original verdict before attributing a change to normalization. Different source fields, ellipses and rewritten suffixes are not formatting differences. Use the authorized short Windows fixture root for deeply nested launcher outputs; preserve a rejected long-path fixture and correct the test environment rather than weakening the runtime guard.
