## Concurrency correction for future scheduling

The user's clarified limit is **up to five dependency-ready arms concurrently**, with **at most five active DeepSeek requests across all arms**. This is independent of the Codex limit of four live agents including root. A provider slot is not a Codex agent slot, and neither limit requires one template to finish before an independent branch can proceed.

Keep each arm's causally dependent stages ordered. One publisher serializes Git updates; it does not globally serialize model execution.
