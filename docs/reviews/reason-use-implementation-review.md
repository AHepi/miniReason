| Receipt | Choice | Why this choice was made | Contribution to the end goal |
|---|---|---|---|
| RU-001 | Retain the staged isolated-use design as an explicitly declared prospective amendment. | RU-004 | Use identical neutral response and use instructions across both return settings. The response instruction says its account is for possible separate use, and the use instruction refers to supplied material and conditionally to an account. | The original wording promised the response would be delivered and presupposed an account was present. | RU-007 | Preserve generic input freezing and leave stimulus selection to the independent material task and parent. Do not add live calls to this review. | These are concrete risks introduced by the new return-path intervention. The no-return control changes only the account field in the use request when comparing identical fixtures. It does not remove reasons already present in the minimal data, the questions or the model's prior knowledge. Self-contained use questions must not require access to unseen J or the omitted full source. Successful account-present use alone establishes neither reason use nor a benefit from Mini; the control permits a narrower comparison. Finite output differences still need passage-level interpretation and remain subject to sampling variability.
