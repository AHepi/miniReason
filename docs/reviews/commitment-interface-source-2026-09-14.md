## What the interface contributes

The earliest specification distinguishes an artifact's opaque content from its interface. A commitment names a bounded application or evaluation; references distinguish **dependence** from **mention**. A warrant identifies the target, commitment, trace and a criticizable claim that the test is sound and relevant. Thus the interface exposes what taking a conjecture up would involve and where a criticism can bear. It is not merely a second copy of an answer or a demand to remember everything.

The new language proposition will preserve that distinction: prose remains expressible, commitments expose scoped consequences and uses, dependence is not inferred from citation alone, and grounds or tests can themselves be challenged. “No usable commitment identified” must remain an expressible outcome. An interface does not certify truth.

This corrects a limitation of H003/H004: the fixture duplicated body into commitments. A distinct text field is necessary for the new comparison but is not sufficient to recover the commitment mechanism. The authored content of that field must express the uptake being proposed.

## What is not inherited

The historical build spec also contains rubric batteries, pass/fail/overrun evaluators, scalar attention machinery and claims about harness adjudication. Those are historical design choices, not current semantic authority. They will not become problem statements, hidden answer keys or admission rules for this study.

FW5 remains the semantic authority. Criticism can be mistaken and still used; a false conjecture can be originative; lost memory does not erase an earlier event. Actual correction requires an argument about what changed and why, not a model label or syntactic acceptance. A commitment's relevance, application and proposed obligation can themselves be criticized. Finite observations cannot establish universal recursive capacity.

## Implementation consequence

Use Mini's existing compiler, artifact reducer and port renderer with an explicitly declared Windows memory-backed execution fixture. The full durable scheduler remains unqualified on this host. New outer scheduling must distinguish template invocations from calls, preserve real body and commitment fields, declare selected field exposure, and limit one coordinator to five concurrent provider calls.

The available renderer has body and body-plus-commitment views, but no commitment-only view. Any such view must be an explicit field projection with source identity and exact-byte custody, not a fabricated model artifact or silent substitution. Published old helpers and records remain unchanged.

No new provider call has been made under this research boundary.
