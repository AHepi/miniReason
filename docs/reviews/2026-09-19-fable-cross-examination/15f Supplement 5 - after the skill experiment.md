# 15f Supplement 5 — after the skill experiment

What this file is: the project-story additions after supplement 15e, verbatim. The report is file 26; its frozen design is 26a; the working notes are 26b.

## Log entries

41. **The skill experiment (file 26).** Two more runs of the file-20
    cross-examination, keeping everything from before. Instead of the plain
    instruction, each witness was handed one of your two method skills as its
    standing instructions: first "hard-to-vary", then "story-critique".
    Before reading a single reply I froze the design and four predictions
    (file 26a). Result on DeepSeek, where both runs finished (27 replies
    each, none empty): neither skill incapacitated it. Both skills found
    every one of the 27 defect groups file 21 had ruled on, and together
    they found about 56 further groups the plain run had missed. The largest
    new one is a second circle in the definitions: a construction counts as
    new only if it is not already in the repertoire, the repertoire is built
    out of constructions, and the primitive that starts the whole chain is
    defined by way of the repertoire. Eight of the fifty-four skill replies
    found it; none of the thirty-six plain replies had. Three false claims in
    fifty-four replies, all on one candidate (the transport-orientation
    passage), all caught by another sample of the same run. The two skills
    are good at different things: hard-to-vary makes the witness say for
    every part what holds it in place and build a rival, so it finds loose
    structure; story-critique makes it check the question against the page
    first and look for promises made and never kept, so it finds unkept
    promises, lists that do not match and definitions never used. Cost:
    replies about half again as long and about a third slower. One defect in
    the skill itself surfaced: the hard-to-vary word list attributes to
    Derivation 2 a claim that file 20 denies, because the list was written
    from file 10.

42. **Atria and the gateway.** Atria's runs are not finished. With a
    55,000-character skill on top of the 92,000-character document, its
    gateway cut most streams or answered with server errors. Two
    hard-to-vary replies landed (both in the skill's report format, one of
    them wrongly marking "no cycle" as held), three items failed after all
    their retries, and the story-critique run had not started when file 26
    was written. What lands goes in a separate supplement 26c; file 26 stays
    as written.
