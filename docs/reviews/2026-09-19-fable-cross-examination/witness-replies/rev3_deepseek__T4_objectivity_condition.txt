1. **Finding 1 — “touches” is not defined.**  
   **Claim attacked:** “touches the anchor — changes the relation of some component in it”; properness uses “components of \(D\) that some pair in \(C_{\mathrm{adm}}\) touches.”  
   **Why it fails:** No comparison class is given for “changes the relation.” Is \(L_j(a,b)\neq L_j(1,b_0)\)? Is it change relative to the previous pair? Does a boundary change \(b\neq b_0\) with \(a=1\) count? For a multi-component anchor, is touching any component enough? The touched-component set of \(D\) is never formally defined, yet silence, properness, resolution, and protection all depend on it.  
   **Severity:** Serious.  
   **Fix:** Define \(\operatorname{Touch}_D(a,b,j)\) explicitly, e.g. \(L_j(a,b)\neq L_j(1,b_0)\), extend it to subnetworks, state whether boundary changes count, and prove the same notion is used everywhere.

2. **Finding 2 — “silent only when” is one-way, but the objectivity condition uses the converse.**  
   **Claim attacked:** “A candidate is *silent* on an admitted pair only when that pair touches no anchor of any active component.”  
   **Why it fails:** “Only when” gives silence \(\Rightarrow\) no anchor touched, not no anchor touched \(\Rightarrow\) silence. The protective clause then says “touches some anchor … so that the candidate is not silent on it,” which needs the converse. As written, a pair can touch an anchor and still be silent.  
   **Severity:** Serious.  
   **Fix:** Define silence by biconditional, or define it positively as “the pair does not change any active component’s transported relation,” and then state the anchor condition as a theorem.

3. **Finding 3 — Hidden ports break the identification of “touching anchor” with non-silence.**  
   **Claim attacked:** “touches the anchor — changes the relation of some component in it”; condition 3 uses anchors with hidden ports, while (F1) only equates a projection.  
   **Why it fails:** A pair can change a hidden component inside an anchor while leaving the projected relation \(\operatorname{proj}_{V_k}[\operatorname{Sol}_{\lambda(k)}]\) and hence \(L_k\) unchanged. The candidate is silent on the visible component, but the condition calls the pair non-silent because it “touches the anchor.” This can both misclassify protection and make the anchored grade incoherent.  
   **Severity:** Serious.  
   **Fix:** Define silence by change in \(L_k(\tau(a),\sigma(b))\) or in the transported answer, not by change in any hidden component of the anchor; or require anchors’ visible ports to include every port touched by admitted pairs.

4. **Finding 4 — Properness over-covers module-live components, not question-relevant components.**  
   **Claim attacked:** “The anchors of the active components refine a cover of the components of \(D\) that some pair in \(C_{\mathrm{adm}}\) touches.”  
   **Why it fails:** \(C_{\mathrm{adm}}\) is the whole module’s admitted edit set. Properness therefore forces active anchors for background components that no part of the question’s query or contract reaches. This contradicts Part 0’s description of an anchored account as “a proper decomposition of the target at the resolution the question needs.” It can exclude a genuine mechanism that abstracts from module-live but question-irrelevant components.  
   **Severity:** Serious.  
   **Fix:** Relativize properness to components reachable from \(C\) or from \(\operatorname{Ans}_p\), or separate “module-live coverage” from “question-resolution coverage” and require only the latter for anchoring.

5. **Finding 5 — If properness is read as written, silence is almost vacuous and objectivity becomes too strong.**  
   **Claim attacked:** “by properness an anchored account is silent on no admitted pair that touches a component the question’s contract reaches.”  
   **Why it fails:** If properness covers every component touched by any pair in \(C_{\mathrm{adm}}\), then every admitted pair that changes any component touches some active anchor. An anchored account is then silent only on pairs that touch no component at all. The objectivity condition would require the candidate’s full transported answer to agree with the target on every admitted pair outside \(C\), even though anchored account-hood only gives component fidelity on touched anchors and does not extend (F2) to all of \(C_{\mathrm{adm}}\).  
   **Severity:** Serious.  
   **Fix:** Either weaken properness to question-relevant components, or extend (F2) and question fidelity to all of \(C_{\mathrm{adm}}\) for anchored accounts, so the objectivity condition is testing the same strength as anchoring.

6. **Finding 6 — The objectivity condition is too weak for non-anchored accounts: \(\lambda\) is candidate-controlled.**  
   **Claim attacked:** “Silence — a pair touching no anchor — is a stated limit of scope, not protection, and it is not under the candidate’s control: it is read off \(\lambda\).”  
   **Why it fails:** \(\lambda\) is part of the transport supplied by the modeller/candidate. Properness constrains \(\lambda\) only in the *anchored* grade, but the objectivity claim is defined for \(\operatorname{Account}(E,p,t,\Gamma)\), not for anchored account-hood. A candidate can choose a sparse \(\lambda\) that omits target components touched by \(C_{\mathrm{adm}}\); excluded pairs touching those omitted components then touch no anchor, are classified as “silence,” and do not make \(C\) protective. The candidate thus protects itself by not covering what it should answer for.  
   **Severity:** Fatal for the claimed objectivity condition.  
   **Fix:** Require anchored account-hood for the objectivity claim, or define protection relative to components of \(D\) touched by \(C_{\mathrm{adm}}\) and relevant to the question, regardless of the candidate’s chosen \(\lambda\). If the candidate omits such a component, that is a failure of objectivity, not silence.

The objectivity condition in Part V is not well-defined as stated. Findings follow; each quotes the passage attacked.

**Finding 1 — “Touches” has no reference point.**
- **Claim attacked:** “every admitted pair that **touches** the anchor — changes the relation of some component in it”; “some pair in \(C_{\mathrm{adm}}\) changes its relation.”
- **Why it fails:** “Changes” relative to what? Baseline \((1,b_0)\)? The previous edit? The same edit at another boundary? If \(a=1\) and \(b\neq b_0\), does the boundary change count as touching the anchor? The definition of structural silence depends on this, and the text never fixes it.
- **Severity:** Fatal.
- **Fix:** Define touch explicitly: \((a,b)\) touches anchor \(U\) iff \(L_j(a,b)\neq L_j(1,b_0)\) for some \(j\in U\), with boundary handling stated.

**Finding 2 — Silence is not read off \(\lambda\) alone.**
- **Claim attacked:** “silence is structural, read off the anchor map, never declared.”
- **Why it fails:** To know whether a pair touches an anchor you need \(L_j(a,b)\) and \(C_{\mathrm{adm}}\), not just \(\lambda\). The anchor map alone does not tell you whether a component relation changes. Also \(\lambda\) is part of the candidate transport \(t=(\pi,\tau,\sigma,\lambda)\), so it is supplied candidate data, not a fact independent of the candidate.
- **Severity:** Serious.
- **Fix:** State silence as a predicate of \((\lambda,D,C_{\mathrm{adm}},L)\), and acknowledge that \(\lambda\) is candidate data.

**Finding 3 — “Only when” is later treated as “if and only if.”**
- **Claim attacked:** “A candidate is *silent* on an admitted pair only when that pair touches no anchor of any active component”; “Silence — a pair touching no anchor — is a stated limit of scope.”
- **Why it fails:** “Only when” gives a necessary condition. The later sentence treats “touches no anchor” as sufficient for silence. That is invalid: a pair can touch no anchor while \(\sigma(b)\) changes the boundary and alters the candidate’s answer, or while a shared constraint changes. The candidate may not be silent at all.
- **Severity:** Serious.
- **Fix:** Define silence as “candidate’s transported answer is undefined or not determined,” and separately define anchor coverage. Prove the equivalence under stated conditions if intended.

**Finding 4 — Properness is too strong for the question-relative grade.**
- **Claim attacked:** “The anchors of the active components refine a cover of the components of \(D\) that some pair in \(C_{\mathrm{adm}}\) touches… no touched component of \(D\) lies outside every anchor.”
- **Why it fails:** Properness covers every component touched by *any* admitted pair, not just components touched by the question’s contract \(C\) or relevant to \(\mathcal Q\). An anchored account is therefore forced to anchor physically touchable components that the question never asks about. That is stronger than “a proper decomposition of the target at the resolution the question needs.”
- **Severity:** Serious.
- **Fix:** Restrict the cover to components touched by \(C\) or by pairs relevant to \(\mathcal Q\), or state explicitly that the anchored grade is a global physical-model condition.

**Finding 5 — Objectivity borrows silence from a grade it does not require.**
- **Claim attacked:** “An **objectivity claim** for \(\mathcal E=(E,p,t,\Gamma)\) is the conjunction of \(\operatorname{Account}(E,p,t,\Gamma)\) and … that \(C\) is **not protective**”; “so that the candidate is not silent on it in the structural sense of the anchored grade.”
- **Why it fails:** Objectivity requires only \(\operatorname{Account}\), i.e. the first grade. Properness is part of the *anchored* grade, not \(\operatorname{Account}\). A candidate can therefore omit anchors, be silent on a relevant admitted change, and avoid protection. The condition is too weak for non-anchored candidates.
- **Severity:** Serious.
- **Fix:** Require the anchored grade for objectivity claims, or define silence independently of properness and forbid anchor omission.

**Finding 6 — “Extended to such pairs by \(\lambda\)” is not well-defined.**
- **Claim attacked:** “the transport being extended to such pairs by \(\lambda\) (the edit acts on an anchored component, so its translation is the corresponding edit on the anchored component of \(E\)).”
- **Why it fails:** \(\lambda\) maps components of \(E\) to subnetworks of \(D\). It does not translate edits. \(\tau\) already translates edits \(A_D\to A_E\). If \(\tau\) is partial, \(\lambda\) cannot extend it. If an edit touches several anchors or also changes non-anchored components, there is no unique “corresponding edit on the anchored component.”
- **Severity:** Fatal.
- **Fix:** Require total \(\tau\) on \(C_{\mathrm{adm}}\) and use \(\tau(a),\sigma(b)\) globally. Delete “by \(\lambda\).”

**Finding 7 — Undefined candidate answers evade protection.**
- **Claim attacked:** “on which the target's answer is defined and the candidate's transported answer differs from it.”
- **Why it fails:** \(\mathcal Q_E\) may be undefined on pairs outside \(C\). If the candidate’s transported answer is undefined, there is no difference, so the pair is not protective. A candidate can evade protection by making \(\mathcal Q_E\) partial.
- **Severity:** Serious.
- **Fix:** Require \(\mathcal Q_E\) to be defined on every pair considered, or treat undefined as protection/failure.

**Finding 8 — Undefined target answers make the condition vacuous.**
- **Claim attacked:** “on which the target's answer is defined.”
- **Why it fails:** Coherently posed requires only that \(\mathcal Q\) is defined on every pair in \(C\). If \(\mathcal Q\) has domain \(C\), then no excluded pair has a target answer, and the objectivity condition never triggers. The condition is then vacuous.
- **Severity:** Serious.
- **Fix:** Require \(\mathcal Q\) to be defined on \(C_{\mathrm{adm}}\) or on all pairs touching anchors for an objectivity claim.

**Finding 9 — Grievance 4 states a different protective condition.**
- **Claim attacked:** Grievance 4: “a contract is protective for a candidate when some physically admitted change it excludes would alter the target's answer and not the candidate's, or the reverse.” Part V: “the candidate's transported answer differs from it.”
- **Why it fails:** Grievance 4 compares alteration relative to baseline and is one-sided (“or the reverse”). Part V compares the candidate’s and target’s answers at the excluded pair. They are not equivalent. Part V catches cases where both answers alter but differently; Grievance 4, read literally, does not. The “or the reverse” is also redundant if Part V’s inequality is intended.
- **Severity:** Serious.
- **Fix:** State one definition. If Part V’s inequality is intended, prove equivalence given baseline agreement and align Grievance 4.

**Finding 10 — Grievance 4 says silence is declared; Part V says it is never declared.**
- **Claim attacked:** Grievance 4: “Where it does not, the candidate is silent, its scope is a stated limit.” Part V: “silence is structural, read off the anchor map, never declared.”
- **Why it fails:** One says silence is a declared scope limit. The other says silence is never declared. Direct contradiction.
- **Severity:** Serious.
- **Fix:** Distinguish declared scope \(S\) from structural silence. State exactly how they relate.

**Finding 11 — “The target is right about itself” assumes target correctness.**
- **Claim attacked:** “The target is right about itself by definition, so ‘the candidate is better’ is not a case.”
- **Why it fails:** Part III explicitly allows that a question may fail to pick out its target or assume incompatible requirements. A target can be wrong about the world. A candidate that is better against the physical module is marked protective under the condition because it differs from the target. The objectivity claim cannot represent the candidate correcting a bad target.
- **Severity:** Serious.
- **Fix:** Separate target self-answer from world answer. Allow “candidate better” as a separate case, or stipulate that the target is an oracle for the question.

**Finding 12 — \(C\) is defined via \(C_{\mathrm{adm}}\), so module growth changes the contract.**
- **Claim attacked:** Part III: “\(C=(C_{\mathrm{adm}}\cap S)\cup K\).” Part V: “a later module with a larger \(A_\Theta\) makes it a new claim at a new index (Part VIII), and account-hood at \(C\) is untouched by it.”
- **Why it fails:** If \(A_\Theta\) grows, \(C_{\mathrm{adm}}\) grows. Then \(C=(C_{\mathrm{adm}}\cap S)\cup K\) grows unless \(S\) is adjusted. So \(C\) is not untouched. The old contract is a different set. The claim “account-hood at \(C\) is untouched” is false unless \(C\) is fixed independently of \(C_{\mathrm{adm}}\).
- **Severity:** Serious.
- **Fix:** Define \(C\) with a fixed admitted set, or make the index explicitly \((C,C_{\mathrm{adm}},\Theta)\) and state how \(S\) adjusts.

**Finding 13 — Derivation 7 does not cover the second index.**
- **Claim attacked:** Derivation 7: “The assessment is indexed to \(C\); its claim keeps its identity and its truth value at that index.”
- **Why it fails:** The objectivity claim’s truth value depends on \(C_{\mathrm{adm}}\). A module change can change the truth value at a fixed \(C\). Derivation 7 only discusses contract change, not module change. It is inconsistent with Part V’s second index.
- **Severity:** Serious.

**Finding 14 — \(K\) is ignored by objectivity, and module growth can break coherence.**
- **Claim attacked:** Part III: “\(K\cap C_{\mathrm{adm}}=\varnothing\).” Part V: “admitted pair \((a,b)\in C_{\mathrm{adm}}\setminus C\).”

The old question becomes incoherent, not merely a new index.
- **Severity:** Serious.

- **Severity:** Serious.

- **Why it fails:** \(\mathcal Q_E\) is not constrained to be the transport of \(\mathcal Q\) outside \(C\). A difference on an excluded pair may be due to a wrong \(\mathcal Q_E\), not scope protection. A candidate can choose \(\mathcal Q_E\) to avoid differences. The condition conflates query translation with scope protection.
- **Severity:** Serious.
- **Fix:** Require \(\mathcal Q_E\) to be the transported query on \(C_{\mathrm{adm}}\), or define transported answer independently of declared \(\mathcal Q_E\).

**Finding 17 — Silence is under the candidate’s control.**
- **Claim attacked:** “Silence — a pair touching no anchor — is a stated limit of scope, not protection, and it is not under the candidate's control: it is read off \(\lambda\).”

- **Severity:** Serious.

**Finding 18 — “The question’s contract reaches” is undefined.**

- **Why it fails:** “Reaches” is not defined. If \(C\) contains only \(K\) pairs touching a component, properness over \(C_{\mathrm{adm}}\) may not cover it, but objectivity ranges over \(C_{\mathrm{adm}}\), so no admitted pair touches it. The clause is either redundant or vacuous.

**Finding 19 — Answer-equivalence can hide component infidelity.**
- **Claim attacked:** “candidate's transported answer differs from it.”
