**Short answer:** For the headline as written — “history determined which kind got expressed” — the trivial argument is stronger. The strongest non-trivial counterargument is not the headline itself but the sign-reversal pattern: two visible things with no occlusion select *against* persistence. ## The trivial argument

The result is close to a restatement of the architecture. The kind under test is persistence, operationalized as the τ gene and `rebind` (design §2.6). τ only matters when a slot is unconfirmed. If a history never produces unconfirmed slots, τ is causally inert. H_neutral is one thing, never occluded, no crossings, so the exact tie is expected: “all four values tie exactly” (results §2). H_full contains occlusion, so τ is exercised. The design therefore contrasts a history where the parameter can act with histories where it cannot, or where it acts differently. That is not a deep discovery about “history determining kinds”; it is the grammar’s own semantics.

## The opposite argument

The non-trivial X is this: H_passive and H_kinematic have **no occlusion**, yet they select τ = 0 strictly — “τ = 0 only” (results §2) — and results §7.4 says persistence “was selected against, not merely not-for.” So the parameter is not only selected under occlusion; its **sign** flips depending on whether unconfirmed slots are caused by occlusion or by two things crossing. There is also the j-gene flip: one-thing histories select `j=yes`, two-thing histories select `j=no` (results §7.1). That is not entailed by “occlusion selects persistence.” It suggests history content can determine not just whether a kind is used, but which direction its selection runs.

## Which argument is stronger?

The trivial argument is stronger for the actual headline. The non-trivial argument is stronger for a revised headline: “history can select for or against persistence, and can flip the jump rule, depending on whether unconfirmed slots arise from occlusion or from crossing/misbinding.” But that revised claim is not the headline, it is partly post hoc, and it is confounded. Section 7 does not rescue the original non-triviality; it offers candidates for a future frozen test.

## A. The triviality argument

**Finding 1 — The headline is entailed by the design.**
(1) Claim attacked: `"History determined which kind got expressed, exactly as the diagnosis said."`
(2) Why it fails: The kind under test is explicitly persistence: `"The kind under test is persistence — the τ gene and the rebind rule."` The only history that contains occlusion is H_full; H_neutral is defined as `"one thing, never occluded, no crossings — nothing in its content distinguishes a thing-tracker from a cell-tracker."` Under the fitness target — predicting true occupancy — persistence only has predictive payoff when occupancy is hidden. So the result “H_full selects τ>0, H_neutral ties” is a relevance check, not an emergence discovery. You built the parameter, built the history where it matters, and then observed that it matters there.
(3) Severity: **Fatal to the headline as an empirical discovery.**
(4) Fix: Restate as “occlusion selects for a pre-supplied persistence parameter.” Or pre-register a case where persistence is fitness-relevant but not selected, or selected without being fitness-relevant.

**Finding 2 — The rival correspondence view is not actually tested.**
(1) Claim attacked: `"Under the rival, it appears regardless."`
(2) Why it fails: A correspondence view can agree that a bounded predictor does not need to represent hidden-thing persistence when nothing is ever hidden. The experiment tests selection among latent read-in rules; it does not test whether kinds are prior inputs. The grammar supplies the kind from the start, and construction is declared out of scope.
(3) Severity: **Serious, close to fatal for the claim that the experiment separates the diagnosis from the rival.**
(4) Fix: Define an independent operational contrast, e.g. interventions on grammar availability, or a fitness-neutral but causally efficacious representation test. Otherwise admit the experiment only ranks latent parameters.

**Finding 3 — “History determined” is contradicted by H_neutral.**
(1) Claim attacked: `"History determined which kind got expressed"` and `"trackers that forget and trackers that never forget tied to the last decimal."`
(2) Why it fails: If the H_neutral selected set contains both τ=0 and τ=∞, then H_neutral did **not** determine which kind got expressed; it underdetermined it. The pre-registered bullet itself says `"the history cannot tell a thing-tracker from a cell-tracker."` Later, 7.3 says `"history did not select between them; which one you got was luck."` That directly contradicts the headline.
(3) Severity: **Serious to fatal for the headline.**
(4) Fix: Reword to “history sometimes selects for persistence; neutral histories leave it undetermined,” or confine the claim to H_full.

## B. The strongest non-trivial argument

The best non-trivial reading is this: the result is not merely “occlusion selects persistence.” It is that the same latent parameter is selected in **opposite directions** by different world structures, and the kind boundary is contract-relative. On H_neutral all τ tie, so cell-tracker and thing-tracker are one kind at that contract. On H_passive and H_kinematic, τ=0 is strictly selected, so persistence is actively harmful when two visible things cross or share cells. On H_full, τ=∞ is selected and passes M3 given-bound 1.000 including occlusion. That is a real contract-relative granularity claim, close to Derivation 2. The M3 component-fidelity result also separates τ=5 from τ=∞ sharply where prediction fitness barely does.

But this non-trivial argument is weaker for the headline as written, for the reasons below.

**Finding 4 — M3 thing-signature is close to definitional.**
(1) Claim attacked: `"The architecture H_full selected is the only one that passes the thing-signature test on every pair it could be tested on, including every occlusion."`
(2) Why it fails: τ=∞ is defined as a thing-tracker that never forgets; τ=0 is defined as a cell-tracker that drops unconfirmed slots. M3 tests exactly that behavior under occlusion. The conditional score `"Passing, given bound"` also ignores the 20% unbound cases, mostly co-located starts.
(3) Severity: **Serious for the strong interpretation; minor as an internal consistency check.**
(4) Fix: Use an independent structural test not defined by τ/read-in rule, and pre-register a binding criterion that handles co-located starts.

**Finding 5 — Search bias is misclassified; the data show bias toward persistence.**
(1) Claim attacked: `"no bias toward or away from persistence"` and section 6 `"Search bias — did not fire."`
(2) Why it fails: The table shows H_neutral seeds converging to τ = 2, ∞, 2, 5, 2, 5. None converged to τ=0, even though τ=0 is in the exhaustive selected set. That is a bias toward persisting architectures. The pre-registered search-bias scenario was exactly that search shape expresses kind without content pressure.
(3) Severity: **Serious to fatal for that classification; also undermines “history determined.”**
(4) Fix: Reclassify as search bias fired; analyze mutation/initialization cause; rerun with neutral initialization or different mutation.

**Finding 6 — The 0.95 ceiling threshold was moved.**
(1) Claim attacked: `"Underpowered — did not fire: adequacy passed before freezing."`
(2) Why it fails: The original pre-registered underpowered condition was `"No slot architecture reaches 0.95 × the sensory ceiling on H_full."` The result is H_full top 0.8009 against ceiling 0.909, i.e. 0.881, below 0.95. The threshold was dropped before freezing after controls. Even if justified, it removes a failure condition after observing it would fail.
(3) Severity: **Serious.**
(4) Fix: Keep the original threshold and report failure; or pre-register a new threshold with independent rationale before seeing relevant data.

## C. Does section 7 rescue non-triviality?

**Finding 7 — Section 7 is post hoc by its own admission and cannot rescue the headline.**
(1) Claim attacked: The implicit use of section 7 to support non-triviality.
(2) Why it fails: Section 7 says: `"These are post hoc. They are reported because they are in the data, not because they were predicted; treat them as candidates for a future frozen test, not as findings."` Post-hoc observations can generate hypotheses, not rescue a headline. 7.1’s `"Nobody declared that; the history did"` is a causal overclaim from a post-hoc pattern. 7.3’s `"which one you got was luck"` contradicts the headline.
(3) Severity: **Serious for the rescue claim; minor as a source of future hypotheses.**
(4) Fix: Freeze a new experiment with predictions for j, drift, and persistence-against; report it as pre-registered or not at all.

**Finding 8 — 7.1 overinterprets the j gene as a “second kind.”**
(1) Claim attacked: `"whether 'displacement' exists as a kind distinct from 'velocity change' was decided by how many things there were. Nobody declared that; the history did."`
(2) Why it fails: j is a specific velocity-correction rule. The comparison is confounded: H_neutral is one thing with no occlusion; H_full is two things with occlusion, swap, and a different change set. There is no two-thing occlusion-only or one-thing occlusion history to isolate the cause. There is also no independent measure of “displacement kind.”
(3) Severity: **Minor to serious if used to rescue non-triviality.**
(4) Fix: Pre-register histories crossing thing count and occlusion; define an independent j-signature.

**Finding 9 — 7.2 is a real pattern but does not establish the headline.**
(1) Claim attacked: `"Prediction fitness is a coarse signal for kind; component-fidelity is sharp."`
(2) Why it fails: It shows two contracts rank architectures differently, not that history determined kind. Under exhaustive selection, a 0.003 difference is still a selection difference. The sharpness of M3 is partly because M3 tests the same persistence under occlusion.
(3) Severity: **Minor.**
(4) Fix: Pre-register both contracts and predicted dissociation; use held-out changes.

## D. Additional referee findings

**Finding 10 — Swap is inert for the fitness target.**
(1) Claim attacked: `"H_full | 2 things | all 24, including occlusion and swap"` and the M2 swap column.
(2) Why it fails: swap exchanges identities; the sensory field is unchanged; true occupancy is unaffected. It cannot affect prediction selection, only M3. Including it in fitness histories is inert and can mislead about what H_full adds.
(3) Severity: **Cosmetic to minor.**
(4) Fix: Mark swap as M3-only or report it separately.

**Finding 11 — H_neutral vs H_full confounds cardinality with occlusion.**
(1) Claim attacked: The H_neutral-versus-H_full contrast.
(2) Why it fails: H_neutral is one thing; H_full is two things. They differ in cardinality, crossings, change set, and occlusion. H_kinematic vs H_full does isolate occlusion within a two-thing world, since swap is fitness-irrelevant. So the occlusion conclusion can be rescued there, but the pre-registered H_neutral bullet is confounded.
(3) Severity: **Minor if H_kinematic/H_full is used; serious if H_neutral/H_full is used.**
(4) Fix: Emphasize H_kinematic vs H_full; add a one-thing occlusion history.

**Finding 12 — “Kinds” plural is an overclaim.**
(1) Claim attacked: `"History determined which kind got expressed"` and the plural `"kinds."`
(2) Why it fails: Only one kind is under test: persistence. The experiment cannot generalize to object, cause, rule, or persistence as a general phenomenon. It tests one parameter family in one grammar.
(3) Severity: **Serious.**
(4) Fix: Restrict the claim to persistence.

---

**Overall adjudication:** The triviality argument wins on the headline as written, because the design supplies the kind, defines the history where the kind matters, and rewards that kind through the fitness target. The non-trivial argument has some force only if the claim is weakened to “the contract determines the granularity and polarity of selection on a pre-supplied persistence parameter.” Section 7 does not rescue the headline; it is explicitly post hoc, and 7.3 in particular contradicts the headline by saying history did not select between the kinds.
