**Finding 1 — The sufficiency counterexample: a built, deployed modular table.**
(1) **Claim attacked.** Part V says: “A table that genuinely encodes an organization’s response to every admitted change is not a table in that sense and is not excluded by (E); it is excluded by properness if it is one component anchored to a target with several, and by nothing if it is a faithful decomposition — in which case it is an account.” Part XV then says such candidates “fail Origin.”
(2) **Why it fails.** Nothing in Origin excludes a table. Let \(E\) be a modular table with one active component per component of \(D\), each component’s relation set to exactly the projected relation of its anchor subnetwork on \(C_{\mathrm{adm}}\). \(E\) satisfies (F1), (F2), (A), non-circular dependence, non-vacuity, properness, resolution, and world-kind. Now let \(s\) build \(E\) from scratch: it is new to \(s\)’s repertoire, built (owned subhistory, nontrivial binding construction, defect record on the route), and deployed (used on an active route to answer \(p\)). Then \(\operatorname{Origin}\) holds. Yet \(E\) is a lookup table of change-responses. It explains nothing beyond “the answer is whatever the table says.” The document’s own text admits it is an account; its only escape is that such tables “fail Origin,” which is false as soon as they are built.
(3) **Seriousness.** Fatal to the sufficiency claim.
(4) **Fix.** Add a condition that the account must not be a mere encoding of the anchor’s change-signature, or require the construction to produce a dependency organization that is not a table of the target’s projected relations. Alternatively, admit that such tables explain and stop saying they do not.

**Finding 2 — Irrelevant defect representation satisfies Build.**
(1) **Claim attacked.** Build requires “an itemised defect representation — an occurrence instantiating a record pairing a state at which some prior transport of \(s\) failed fidelity with what would have held — on an active route to the binding.”
(2) **Why it fails.** The clause does not require the prior failure to be about \(c\), about \(D\), about \(p\), or about the binding being constructed. A system can use any prior failure record — e.g., a failed weather prediction — as the defect representation. So long as that record is on the causal route that led to the binding construction, Build is satisfied. This makes Build almost trivial.
(3) **Seriousness.** Serious.
(4) **Fix.** Require the defect representation to be a failure of a transport of \(s\) on the target or a relevant subnetwork, and require the record to be causally connected to the specific binding constructed.

**Finding 3 — Attempt can be satisfied by a trivial obligation.**
(1) **Claim attacked.** Attempt requires “some obligation in \(O_p\) fails at the state before \(e\).”
(2) **Why it fails.** \(O_p\) is declared by the modeller. It can contain an arbitrarily trivial obligation, e.g., “\(s\) should have a copy of \(D\).” If \(s\) then builds and uses a copy, the obligation fails before and is addressed after. This satisfies Attempt for a question that is not an explanatory question in any substantive sense.
(3) **Seriousness.** Serious.
(4) **Fix.** Require the obligation to be non-trivial and to be connected to the target’s behaviour, or add a merit condition on questions — which the document elsewhere admits it lacks.

**Finding 4 — Newness allows a copy of the target.**
(1) **Claim attacked.** \(\operatorname{New}(s,c,h,e)\) requires “no prior deployable equivalent” in \(s\)’s repertoire.
(2) **Why it fails.** If \(s\) never had \(D\) in its repertoire, a built duplicate or faithful modular table of \(D\) is new. The definition of \(\equiv_\ell\) is content-preserving recoding. A duplicate of \(D\) is not in the prior repertoire merely because \(D\) itself exists in the world. So New does not filter out copies of the target.
(3) **Seriousness.** Serious.
(4) **Fix.** Require that the new content not be a faithful copy of the target’s organization, or that it be new relative to a repertoire that already includes the target’s own organization.

**Finding 5 — Properness over-covers components relative to the question.**

**Finding 6 — Properness forbids global or whole-target anchors for multi-component targets.**

(2) **Why it fails.** Many genuine mechanisms are global: a single force law, a conservation law, a field equation, a gauge constraint. (3) **Seriousness.** Serious.
(4) **Fix.** Allow a whole-target anchor when the question asks about a global property, provided the anchor’s signature on \(C_{\mathrm{adm}}\) matches the whole target and resolution is otherwise satisfied.

**Finding 7 — Resolution uses \(C_{\mathrm{adm}}\), not the question’s scope.**

**Finding 2 — Direct contradiction between Part V and Part XV about modular tables.**
(1) Claim attacked: Part V: “So is a modular table whose pieces each carry the local signature of an anchor on every admitted edit. Both are extensional copies of the mechanism at this grain.” Part XV: “Candidates meeting the anchored grade and explaining nothing are already known — the target’s own copy, the faithful modular table.”
(2) Why it fails: If a faithful modular table is an **extensional copy of the mechanism**, then it explains as well as the mechanism does. If it is a candidate that **explains nothing**, then it is not an extensional copy of the mechanism in any explanatory sense. The two statements cannot both be true unless the mechanism itself explains nothing, which would undermine the example.
(3) Seriousness: **Fatal** to the coherence of the extensional stance.
(4) Fix: Clarify whether “faithful modular table” means a table of observed answers (which fails (F1) under interventions) or a genuine faithful decomposition (which then explains). Do not call it both an extensional copy and a non-explanation.

**Finding 3 — Non-circular dependence is not enforced by its witness.**
(1) Claim attacked: “The target’s answer does not appear, at the declared grain, as an unanalysed boundary input or as a component… The witness: there exists an edit \(\tau(a)\) on \(E\) … that removes or replaces a nonempty proper sub-block \(B\subsetneq\Gamma\) … under which the answer profile changes.”
(2) Why it fails: The prose forbids the answer appearing as a component. The formal witness only requires that removing some proper sub-block changes the answer. A candidate with a component whose relation is literally the answer function satisfies the witness: remove that component, and the answer profile changes. There is no check that the removed sub-block is not itself the answer function, nor that the remaining components compute it.
(3) Seriousness: **Serious**. It reopens the door to trivial restatements.
(4) Fix: Require the witness to show that no proper sub-block is itself a component whose relation is the answer function, or require the answer to be computed from components that are independently anchored and not identical to the answer relation.

**Finding 4 — World-kind excludes idealizations and partial mechanisms.**
(1) Claim attacked: “World-kind. Each active component of \(E\) is of one forward kind, on \((\ell,C_{\mathrm{adm}})\), with its anchor subnetwork.”
(2) Why it fails: An idealization such as the ideal gas law is not faithful on every physically admitted change (e.g., high pressure). A partial mechanism that correctly captures only some dependencies also fails world-kind on the remaining admitted edits. If the document claims the anchored grade is what “matches the mechanism” means at the module’s index, it excludes genuine explanations that are idealized or partial by design.
(3) Seriousness: **Serious**. It confuses “complete fidelity on the full admitted contract” with “genuine explanation.”
(4) Fix: Allow anchored accounts relative to a declared scope, or distinguish idealization/partial mechanism from full mechanism at separate grades.

**Finding 5 — Single-component targets make the anchored grade trivial.**
(1) Claim attacked: “An anchor may be the whole target only when \(D\) has one component.”
(2) Why it fails: If \(D\) is declared with one component—even when the physical module licenses a finer decomposition—then properness is automatically satisfied by a one-component candidate anchored to the whole target. Resolution is vacuous. World-kind is satisfied if the one component matches the target’s relation on all admitted edits. A system can build a new one-component black-box copy, satisfy Origin, and explain nothing about the internal dependencies. The anchored grade does not force the finest licensed decomposition.
(3) Seriousness: **Serious**. It admits black-box restatements as anchored explanations.
(4) Fix: Require the grain to be the finest licensed by the module for the question, or add a condition that the target not be a black box for the question asked.

**Finding 6 — Coarse grains are under-constrained by admissibility.**
(1) Claim attacked: “A grain is admissible … when the physical module licenses an organization at that grain … and every component of that organization is touched by some admitted pair.”
(2) Why it fails: Admissibility does not require the grain to be fine enough for the question. A coarse-grained anchored account can conflate distinct mechanisms that are separate at a finer licensed grain. The document admits that a decoy with the same response on every admitted edit is “at that index the mechanism,” but this only holds if the index is the right one. Nothing in the anchored conditions forces the right index.
(3) Seriousness: **Serious**. It allows coarse-grained trivial explanations to count as anchored.
(4) Fix: Tie admissibility to the question’s resolution needs, or require that any finer licensed grain that separates dependencies with distinct effects on the answer be used.

**Finding 7 — The objectivity condition is vacuous under silence.**
(1) Claim attacked: “\(C\) is protective when there is an admitted pair \((a,b)\in C_{\mathrm{adm}}\setminus C\) on which the candidate is evaluable — \(\tau(a)\), \(\sigma(b)\) and the query are all defined there — and on which the candidate’s pulled-back answer differs from the target’s.”
(2) Why it fails: If the candidate simply never defines \(\tau\) on excluded pairs, it is never evaluable there, so \(C\) is never protective. Objectivity can be trivially satisfied by restricting the transport’s domain. The document calls this a “stated limit of scope,” but a candidate can be silent on every excluded pair, making the second index empty.
(3) Seriousness: **Serious**. It undermines the claimed objectivity condition.
(4) Fix: Require the transport to be defined on all of \(C_{\mathrm{adm}}\), or require a substantive justification for each silence, not merely a declaration.

**Finding 8 — Build’s defect representation clause does not require content use.**
(1) Claim attacked: “contains an itemised defect representation — an occurrence instantiating a record pairing a state at which some prior transport of \(s\) failed fidelity with what would have held — on an active route to the binding.”
(2) Why it fails: The clause requires the record to be on an active route, but does not require the binding construction to depend on the **content** of the record. A blind search that happens to have a detailed error log on the route, but never reads it, can satisfy this. That collapses construction into selection with decoration.
(3) Seriousness: **Serious**. It weakens the distinction between construction and blind selection.
(4) Fix: Require the binding to depend on the content of the defect representation, e.g., that altering the record’s content alters the binding in the specified way.

**Finding 9 — The physical module is a decomposition oracle.**
(1) Claim attacked: “The physical module \(\Theta\) … the instantiation relation inside it is a decomposition oracle: that is what ‘physics says what a lump instantiates’ costs, and it is listed rather than hidden.”
(2) Why it fails: The semantics delegates the hard problem of mechanism identification to a primitive that must return a full organization—ports, domains, components, footprints, boundaries, admitted edits, and every component relation—for any lump at any grain. This is not a minor primitive; it is the entire problem of finding mechanisms. The theory then claims to explain explanatory creativity while assuming the oracle does the explanatory work.
(3) Seriousness: **Serious** to the philosophical project. It makes the theory conditional on an unanalyzed oracle.
(4) Fix: Either derive the decomposition from simpler primitives or state clearly that the theory is conditional on an external theory of mechanism individuation.

**Finding 10 — F2 forces the explanation to be a quotient of the target.**
(1) Claim attacked: “\(\pi[\operatorname{Sol}_D(a,b)]=\operatorname{Sol}_E(\tau(a),\sigma(b))\).”
(2) Why it fails: This requires every solution of \(E\) to be the image of a solution of \(D\). If \(E\) introduces a new independent port not functionally determined by \(D\)’s ports, F2 fails. Many genuine explanations introduce hidden entities or new degrees of freedom not already present in the target’s declared organization. They are excluded by the transport formalism.
(3) Seriousness: **Serious** for necessity (attack (B)), and relevant to sufficiency because it restricts what can count as an anchored account.
(4) Fix: Allow transports that introduce new ports with their own domains, or explicitly limit the semantics to re-descriptions of a fixed physical decomposition.

**Finding 11 — Selection witness requires exact fidelity as the survival condition.**
(1) Claim attacked: “a survival condition that holds of a member exactly when it is faithful on \(H\) (fidelity on \(H\) is necessary and sufficient for survival).”
(2) Why it fails: Real selection typically depends on fitness, not exact fidelity on a finite history. The Derivation 3 result is therefore about a very special population. The document admits this, but it still presents selection as a general provenance for correspondences.
(3) Seriousness: **Serious** for the claim that selection produces correspondence in general.
(4) Fix: Parametrize the survival condition, or state that the result only applies to selection under exact fidelity filtering.

**Finding 12 — Bearing requires account-hood, which is too strong for criticism.**
(1) Claim attacked: “\(\operatorname{Bearing}(c,z,p_\delta)\iff\operatorname{Account}(E_c,p_\delta)\).”
(2) Why it fails: A criticism can correctly identify a defect without itself being a full account of the question about the defect. Requiring account-hood excludes partial or informal criticisms that are nonetheless bearing. The document says an adverse signal is not a criticism until an organization represents how it bears, but it does not justify why that organization must satisfy all five conditions of Account.
(3) Seriousness: **Minor to serious** depending on how central criticism is to the project.
(4) Fix: Allow bearing when the criticism supplies an organization that is a partial account, or that can be repaired to an account, rather than requiring full Account.

**Finding 13 — Inconsistent treatment of lookup tables.**
(1) Claim attacked: “A table of observed answers has no component whose relation is replaced by an intervention; it fails (F1) under any contract containing one.”
(2) Why it fails: A lookup table can be represented as an organization with a component relation \(L(input,output)\) that is the full lookup. Under an intervention on the input port, the component assigning the input is replaced, but the lookup component’s relation remains in force. The table can satisfy F1. The document later admits: “A table that genuinely encodes an organization’s response to every admitted change is not a table in that sense and is not excluded by (E).” The initial blanket statement is imprecise.
(3) Seriousness: **Minor**.
(4) Fix: Distinguish a set of observed pairs from a table that encodes a relation; only the former fails F1.

**Finding 14 — Finite monotone theorem is conditional in a way that limits its use.**
(1) Claim attacked: “If \(\Gamma\) is finite, \(\mathsf S\) is upward closed, and \(\Gamma\in\mathsf S\), then the critical singletons are exactly \(\bigcup\min\mathsf S\) and the globally indispensable ones are exactly \(\bigcap\min\mathsf S\).”
(2) Why it fails: The theorem assumes \(\Gamma\in\mathsf S\), i.e., the full candidate is an account. The document itself gives an interference example where the full candidate fails although a subset succeeds. In such cases the theorem does not apply, and the interesting structure of support is not covered.
(3) Seriousness: **Minor**.
(4) Fix: State the theorem explicitly as conditional on full-candidate account-hood, and provide a separate treatment for the interference case.

**Finding 15 — Unproved claim in the skew-symmetric example.**
(1) Claim attacked: “The full Leibniz expansion with skewness substituted satisfies (F1) and (F2): every intermediate product is a determinant suborganization whose hidden ports project away.”
(2) Why it fails: This is asserted without proof. “Hidden ports project away” is a vague condition. For a mathematical organization, the admission relation is declared, and the claim that the Leibniz expansion is faithful on all declared edits requires checking F1 and F2 explicitly, not by metaphor.
(3) Seriousness: **Minor** for the overall argument, but it weakens the example.
(4) Fix: Provide the explicit organizations and check (F1) and (F2) pointwise, or mark the example as illustrative only.

**Finding 16 — The extensional stance is internally inconsistent with the use of “explains nothing.”**
(1) Claim attacked: “Both grades are extensional: the target’s own faithful copy satisfies them, and whether a copy explains is a question about origin and deployment (Part X), not about fidelity.”
(2) Why it fails: If account-hood is extensional and a faithful copy is an anchored account, then a faithful copy that satisfies Origin should explain. The document repeatedly says that faithful modular tables and the target’s own copy “explain nothing.” The only way to reconcile this is to say that they fail Origin. But a built faithful copy can satisfy Origin (Finding 1). Therefore the extensional stance plus Origin entails that a built faithful copy explains, contradicting the document’s claim that such copies explain nothing.
(3) Seriousness: **Fatal** to the sufficiency claim.
(4) Fix: Either admit that built faithful copies do explain, or add a non-extensional condition to explanation that distinguishes genuine mechanisms from mere faithful copies. The latter would require abandoning the claim that account-hood is purely extensional.

**Finding 17 — The question-provenance condition is circular.**
(1) Claim attacked: “A **constructed** question is one whose representing transport is constructed. Any assessment may use any of the three. A claim that an episode found a question requires \(\rho_p=\text{constructed}\) with the witness.”
(2) Why it fails: The provenance of a question is defined via the provenance of the transport that represents the question-organization. But the question-organization itself is constructed in Derivation 5, which is a sketch with gaps. Until those gaps are closed, the provenance of a question is not well-defined. The document admits the sketch is conditional, so the claim that question-finding is representable is conditional on an unfinished construction.
(3) Seriousness: **Serious** for the claim that question-finding is on the same footing as answering.
(4) Fix: Complete Derivation 5 or clearly mark question-provenance as conditional and not yet usable.

**Finding 18 — “No instance of (EK) is asserted” leaves the knowledge-creation class empty by admission.**
(1) Claim attacked: “No instance of (EK) is asserted in this document.”
(2) Why it fails: If no instance is asserted, the central class of created explanatory knowledge is unpopulated. The document may say it defines the class, but the definition is so complex and conditional on so many primitives and undeveloped sketches that it has no demonstrated application.
(3) Seriousness: **Serious** for the project’s claim to characterize explanatory creativity.
(4) Fix: Provide at least one worked instance of (EK), or state clearly that the class is currently empty and the definition is programmatic.
