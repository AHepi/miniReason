The control's delta omission has an exact small witness. Start with L={(1,7)} and empty R, so the output contains (1,7,NULL). Inserting R(9,7,x) must replace that row with (1,7,x). Control §4.3 only emits the new matched row, so its listed delta leaves both rows. Conversely, deleting the only matching right row should restore NULL-extension, but §4.4 only retracts the matched row. The selected Mini and direct sample explicitly specify both swaps.

This does not defeat every interpretation of the control. Its retained value bags and counts change correctly, and its declared decoder reconstructs the correct complete result. It expressly treats the output as derived rather than retained. The finding is a conflict between its claimed signed deltas and its declarative output relation; a reader who follows the decoder can avoid the delta error. The chosen observation/update route must therefore be identified before calling a later use correct or incorrect.

The selected Mini has the converse local advantage/disadvantage pattern in its written instructions: it specifies the right-side swaps but omits explicit retained-row removal in the NULL-key left-delete branch. The [selected-account review](E027-selected-account-review.md) and exact two-reading diagnostic distinguish correct immediate delta from stale retained state and a later reconstruction failure. Both direct and control explicitly remove the left-state row outside their key-branch condition. None is substituted for the preselected occurrence.

The control's right-side compression is legitimate under guaranteed legal full-before-image events. A per-key bag of values preserves projected multiplicity even when distinct right IDs share a value; the event already supplies the deleted key and value. Retain value bags for keys with no current left match so later left insertions can use them. Right rows with NULL keys never join. Inability to validate illegal right-ID operations is outside the supplied contract. Consequently the direct sample's assertion that rid is needed for deletion, and the selected sample's claim that retained Rrows is needed to recover a deleted value, exceed what this contract requires. Their larger state may still be sufficient and useful.

The transferable research distinction is between representable information, chosen state access and actual performed updates. Here one account can state an adequate decoder and inadequate delta operations together. A single endpoint bag cannot adjudicate every retained-state commitment, and a missing explicit operation need not prevent an LLM interpreter from supplying it. E028 will preserve its selected account and make its own concrete decoding/caching choices explicit rather than equate syntax or a finite oracle with explanatory bearing.
