## Candidate gap: which transition tests representation?

ECS Part 0 P1 names a content change leaving attributed transitions invariant as a falsifier of a proposed representation supply. Sections 5.1–5.2 separately require an active route with nonconstant dependence for reason use. The object of the word attributed matters. Representation and use cannot be identified merely because both are assessed through transitions.

Fix a system boundary containing an archive, a decoder and a use stage. Let two records r1 and r2 represent distinct fictional rules c1 and c2. The decoder preserves that distinction: d(r1)=c1 and d(r2)=c2. The use stage deliberately receives neither record and returns an unresolved answer for either. Thus u(r1)=u(r2), while d(r1) differs from d(r2). This finite construction is a countermodel to the broad implication that invariant final decisions necessarily entail absent representation. It does not rely on an LLM observation. Its premises explicitly supply the decoder's representation interpretation.

That broad implication is not unambiguously ECS's claim. The strongest counterreading indexes P1 to the operation used in the representation attribution. Here the attributed decoding transitions differ; the invariant use stage establishes no active route from the record. This reading reconciles P1 with §§5.1–5.2 and defeats the proposed inconsistency. The surviving finding is a scope-clarification candidate, not an established flaw in the constitutive conjecture and not an (E)-sufficiency or necessity counterexample.

A candidate clarification would require a P1 supply to name its represented distinctions and the particular operation whose transitions test them. A content change that ought to change that declared operation but does not would challenge the supply. Invariance of an unrelated or inactive operation would not. Meaning-preserving recoding likewise concerns contracted distinctions, not literal equality of every emitted string. This clarification is a proposed addition to application discipline; it is not installed as a revision to ECS.

If the source's phrase attributed transitions already determines this scope adequately, the semantic candidate adds no new condition. The routing experiment can still be useful engineering evidence. Conversely, if no independent operation can be specified without defining representation by the desired result, the application has exposed a P1 supply problem. That remains short of showing that every admissible P1 supply is circular or empty, the stronger defeat condition in ECS §10.2.

## A discriminating next configuration test

A prospective fixture can supply the fictional rule accept exactly when the count is one, a meaning-preserving recoding, a changed rule accept exactly when the count is two, and the original with irrelevant padding. The decision question fixes count one and explicitly requires an unresolved answer when the rule is unavailable. An operator-controlled source/decode stage preserves each record; a distinct one-cycle use template either receives that exact record or has it withheld. The record is the only stipulated authority for the fictional rule.

| Content condition | Record returned: warranted answer | Record archived only: warranted answer |
|---|---|---|
| Original rule, count exactly one | Accept | Undetermined |
| Meaning-preserving recoding | Accept | Undetermined |
| Changed rule, count exactly two | Reject | Undetermined |
| Original with irrelevant padding | Accept | Undetermined |

Crossing these four conditions with returned/withheld and native thinking disabled/enabled would require sixteen single-call use observations. This is a proposed diagnostic block, not a frozen plan or executed comparison. A source/decode template followed by a distinct use template respects the user's different-template requirement. Exact materials, boundaries, interpretation, controls, cost accounting and provider settings must be frozen before any observations. Direct/Mini prompt parity can first be verified with scripted responses; duplicate live routes only for an independently stated operational comparison.

The decoder is an operator contribution. Its success establishes a representation supply for the declared combined system, not that the model internally represents the same content. Response differences establish functional dependence under the declared contrast; they do not alone establish ECS reason use, which additionally requires the representation-preserving structural map into the response organization. The model may use surface cues, expose an unanticipated interpretation or retain the same final answer for different operative reasons. Preserve those possibilities. The fictional fixture tests a narrow routing and deployment mechanism; it is not a creativity task or evidence of historical newness. Its inputs are rules, not criticism occurrences, so it cannot establish that a criticism bears or is used. Independent challenge defeats the proposed P1 contradiction under the scoped-transition interpretation; the wording clarification does not fill a demonstrated semantic gap.

The inference fails if the withheld input leaks through another field, the rule is supplied by another source, the alleged recoding changes content, the decoder loses the retained distinction, or the chosen grain identifies the two rules. These are checks on the proposed application. A successful result would witness the tested routing/use behavior; it would not validate ECS across other cases.

## Gaps that must remain separate

The [semantic guide](../SEMANTIC_GUIDE.md) already records rendered defects in §2.3's graded-accounting formula and §3.4's hard-to-vary formula, plus constructions retained by reference to ECS 1.0. These are known document-completeness problems. The newly attached PDF is byte-identical to the stored source; no new source revision or newly discovered defect is claimed. Any reconstructed formula must be a separately identified proposal with stated assumptions.

Whether §3.4's anchoring determines an intrinsic variation family remains a substantive attack locus named by ECS itself. Missing adapters, unavailable prior-repertoire information and insufficient observations are implementation or evidence limitations. Neither category is interchangeable with a sufficiency counterexample. For that challenge, all accounting conditions and relevant primitive supplies must survive under a fixed grain while an independent case argument establishes absent explanation.
