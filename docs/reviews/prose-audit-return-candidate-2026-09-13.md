# Candidate: prose_audit_return_v1

**Best current use:** supervised auditing of prose specifications, analytical reports, and stateful operating rules where an earlier mistaken assumption can affect later decisions. This is an experimental template architecture, not a validated autonomous auditor or a claim of a historically new language.

## Concrete template

| Step | Work | Material to retain for return |
|---|---|---|
| 1. Account and problem | State the working account, question, source claims, assumptions, consequences, and any supported problem. | The actual account and its question. |
| 2. Criticism | Examine that account and its representation for errors, unsupported assumptions, and consequential gaps. | The objection and its precise target. |
| 3. Criticism of criticism | Check the objection's target identity, grounds, scope, and assumptions. Separate a valid objection, a mistaken one, and an open question where warranted. | The criticism and the original target needed to assess it. |
| 4. Operative return | Say which working uses or interpretations are retained, revised, withdrawn, or suspended; attribute each change to the present contribution. | The changed working account and relevant surviving consequences. |
| 5. Fresh use | Apply the working account to a new case, recompute a protected earlier case, and expose any representation/contract discrepancy. | Actual results, explanation, and a remaining problem only if supported. |

Repeat with new questions or cases and selected older targets. H003/H004 instantiated **20 model steps: four five-step blocks**, rather than twenty complete five-step blocks. Each arm received its previous own response and the frozen schedule's selected earlier responses. It did not receive every archived response or another arm's work.

Continuity serves later inspection and correction of particular claims. It does not require perfect memory. Re-present an earlier target with its occurrence identity and exact available text; distinguish its original wording from a current interpretation. A preserved prefix remains usable evidence at its actual scope, with its missing ending explicitly unavailable.

It is not a generic replay command for new projects; a new instance needs its own declared material, boundaries and occurrence.

The [terminal root report](../../experiments/diagnostics/H004-partial-language-continuation/REPORT.md) records five policies reaching20steps, with100uniquecombined calls:50complete/50partial. Both WHL and RSS were available in every policy, including prose. The study contains useful corrections, but also false provenance allegations, faulty counterfactuals and criticism errors that survive a return. All final contract D/A sets were correct; their explanations were not consistently correct.

WHL and RSS remain incomplete custom proposals built from familiar ideas. Historical novelty is unestablished. Prose conversion is a candidate method for exposing additions, losses and assumptions; this study does not show that either conversion policy outperforms prose.

## Operating discipline for a new instance

- Keep the source claim, current interpretation, criticism and changed use distinguishable. A model's assertion that a target was missing or truncated is itself a claim to check against that occurrence's receipt and input.
- Let a current evidence limitation warrant a scoped suspension. Do not infer that an earlier investigator lacked evidence from its absence in the current context.
- Review both fresh outputs and their explanations. Correct answers can coexist with a false account of why they are correct.
- Preserve partial contributions and unsuccessful outcomes. Declare a partial-admission rule prospectively; never reconstruct a missing ending or quietly change an old observation.
- Run independent ready arms concurrently within the actual provider limit; retain causal ordering and publication gates inside each arm.

The observed H004 settings were DeepSeek flash, thinking disabled,4096completion tokens per call,180second timeout, no retries, at most5active requests. It used a canonical in-memory routing fixture, not the full durable scheduler.

## What would strengthen the candidate

A matched successor should test whether a specific warranted correction made operative changes later use, compared with the same content archived outside the active route, while preserving protected achievements and controlling task information and call budget. That would address criticism's causal contribution. Further iteration alone does not answer it.

The present result supports supervised use and investigation. It does not establish historical newness, universal recursive capacity, a native-reasoning advantage, or reliable autonomous error correction.
