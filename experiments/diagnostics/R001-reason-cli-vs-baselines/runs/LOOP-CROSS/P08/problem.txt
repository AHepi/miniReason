Six nonpreemptive jobs share one machine. Time begins at 0. The machine can process at most one job at once, a started job must run to completion, and no job can start before its release time. Idle time is allowed even when a job is available. There are no setup times, precedence constraints, or other restrictions. A job completing at time t frees the machine for another job to start at exactly t.

Job A: release time 0, processing time 5, weight 3.
Job B: release time 2, processing time 2, weight 9.
Job C: release time 1, processing time 4, weight 4.
Job D: release time 5, processing time 1, weight 7.
Job E: release time 0, processing time 3, weight 2.
Job F: release time 7, processing time 2, weight 6.

Let C_J be the completion time of job J. Find a schedule minimizing the sum over all six jobs of weight(J) times C_J. Give the exact minimum, the order, and every start and completion time, including any idle interval. Explain why the proposed schedule is globally optimal, not just locally preferable. Real-valued start times are allowed.

Reason in prose from this problem. No code execution, calculators, external tools, or retrieval are available. Give an exact answer and a checkable public explanation.
