## The first criticism (WHL has no "declared standard reading") — sound in substance, over-stated in exactly the way it accused Cycle 1 of over-stating

Cycle 2's first criticism says Cycle 1's label "the declared standard reading" misattributes to WHL a preference WHL disclaims, because WHL's own notes say "the language does not choose between them," and `deletion_changes_greatest` is introduced as "a possible disagreement, not resolved." I agree with this against the *WHL* framing: WHL does not rank `reserves_effect` above `expired_deletes_rule`. The reattribution — the R3/R4 rule is authority of the **contract**, not of WHL — is correct and should be returned to Cycle 1's method.

But Cycle 2 then does something it did not flag in itself. It says A1's deletion reading "conflicts with the *contract*," and it says the deleted reading "must be announced and justified" is itself an over-statement — but the reason it gives (WHL is neutral, so justification is not a *special* burden) is a claim about WHL, not about the contract. The contract does not merely fix R3/R4 as one reading among many; it says (preamble to R1) that where the specimens disagree with the contract, the disagreement should be **exposed rather than silently changed**. So the accurate statement is:

- Against the **contract**: A1 is wrong; the deletion reading is excluded, and this is not a tie.
- Against **WHL**: the language is neutral between the two readings; WHL gives no authority either way, and `expired_deletes_rule` is a legitimate representable rival.
- The *grounds* for saying A1's deletion reading is wrong is the contract, not WHL. That ground must be stated, because WHL supplies a competing neutrality.

Cycle 2 got to an equivalent statement, but it blurred the difference between "WHL's preference" (which is what Cycle 2 said Cycle 1 misattributed) and "the contract's preference" (which is real). That distinction is the whole point of Cycle 2's criticism, so it matters that Cycle 2's own wording keeps it. A nearly useless refinement: Cycle 2 called the deletion reading "a mere rival"; that phrasing is not the correct target, because WHL does not minoritize it at all. The disanalogy between "contract rule" and "WHL neutrality" is not that WHL under-weights its own alternative — it is that WHL does not *rank*, whereas the contract does *decide*. Preserve both facts.

I return to Cycle 1's method: keep A1 defective; state WHL is neutral; state the contract decides; do not resolve the disagreement silently.

## The second criticism (WHL bounds may be wider than the exact set) — sound, and correctly applied, but the fix it proposes is itself incomplete

Cycle 2's second criticism is the one I judge most useful and it survives. Cycle 1 quoted "global availability bounds (as intervals over integers)" and used `availability_lower_bound`/`availability_upper_bound` as the WHL vocabulary for availability, while separately (and correctly) invoking R6 against A2's `[-3,2]` substitution. Cycle 2's point is exact: the WHL bound functions sum per-booking *extrema*, whereas the exact attainable set is the sum over the *admissible combinations* of per-booking `possible_reservations`. The extrema-sum can widen the interval past the attainable set whenever the per-booking reservations can't be jointly realized — precisely the R6 "intervening admitted integer values" condition. This is a real internal inconsistency in Cycle 1, and Cycle 2 rightly applies the R6 rule to the *endorsed vocabulary* rather than only to the critic.

However Cycle 2's fix is stated too weakly. It says: "obtain the exact attainable set from the sum over independently-but-exactly chosen per-booking reservations (each from its own `possible_reservations`), and check R6's intervening-value condition before ever presenting an interval as the exact set." That is right as far as it goes, but it does not say **when** the extrema-sum can equal the exact set. A stronger and more honest statement, still inside the sources:

- The exact set is `{ capacity − Σ_b q_b : q_b ∈ possible_reservations b }` over the admissible per-booking choices (R5: choices independent; R6: one selection per booking at greatest revision).
- `availability_lower_bound`/`availability_upper_bound` are only guaranteed to bracket that set, not to equal it, because independence across bookings does not imply the extrema are jointly attained.
- The interval equals the exact set only when the exact set is itself an integer interval with all intermediate admitted values occurring (R6), which is a *snapshot-specific condition*, not a fact about the bound functions.

Cycle 2 correctly caught the conflation and correctly prescribed the test, but did not name the condition under which the bound functions may legitimately be reported as the exact set. Returning this to Cycle 1's method: report `availability_lower_bound`/`availability_upper_bound` as bounds; derive the exact set from the admissible combinations; state R6's intervening-value condition as the criterion; do not present bounds as the exact set absent that check.

## The third item (RSS silence on provenance weighting) — Cycle 2's refinement is right, and Cycle 2's own wording of it is right, not new error

Cycle 1 said A4's authority-weighting is "unsupported in both sources" and treated RSS as if it might oppose it. Cycle 2 refined: RSS is *silent* rather than *opposed*, so A4's verdict stands and the reasoning around it shrinks. I agree. RSS gives provenance to stories, treats exact duplicates as requiring equal provenance, treats near-duplicates as conflict material, and — on its own account — "does not rank them." It neither endorses nor forbids weighting distinct provenance as extra authority. So Cycle 1's conclusion (A4 defective) survives, and the *ground* is narrower than Cycle 1 suggested and broader than "RSS opposes it": A4 imports a corroboration/authority model that neither the contract nor the selected WHL representation supplies, and that RSS does not supply either but also does not forbid. Cycle 2 stated this correctly. It should be preserved as scope, not escalated to a defect in Cycle 1, and Cycle 2 already framed it that way. No change needed beyond preserving it.

## The fourth item (Cycle 2's "consequential problem" restatement) — partially open, not a clean defect in Cycle 1

Cycle 2 restated Cycle 1's "one consequential new problem" as: "A1 substitutes a reading *the contract excludes*; A2, A4, A6 import policies *neither the contract nor the selected representation supplies*." This is closer to correct than Cycle 1's flat "each silently imports a reading," but it still glosses A6. A6's issue is not an imported *policy* in the same sense as A2's interval substitution; A6 asserts a *constraint the contract explicitly disclaims* (R5: alternatives of different bookings are independently admissible; no cross-booking constraint has been supplied). A2 and A4 import unsupplied material; A6 *contradicts expressly supplied material*. These are different failure modes and should be reported as such:

- A1: substitutes a reading the contract excludes (reading choice).
- A2: substitutes an interval for an exact set without the R6 condition (representation/equality error).
- A4: imports an authority-weighting model not supplied by contract or WHL (extraneous model).
- A6: asserts a cross-booking exclusivity constraint that R5 disclaims (contradicts a supplied rule, and self-undermining because its own clause admits the constraint wasn't supplied).

Cycle 2's corrected phrasing therefore improves on Cycle 1 but still lumped A6 with the others. This is a genuine scope correction that should return.

## Explicit answers to the three outcomes the task names

- **Valid criticism.** Cycle 2's second criticism, tightened as above (bounds vs. exact set; state the R6 condition under which an interval may be reported as exact), is valid and should enter Cycle 1's method.
- **Invalid or over-stated criticism.** Cycle 2's first criticism is substantively right but over-states by treating the WHL/contract distinction as itself a WHL preference; the correction is to name the contract as the deciding ground for R3/R4 and to keep WHL's neutrality as a distinct, separately stated fact. This is a correction of the criticism's *label and grounds*, not of its verdict.
- **Still-open question.** Whether, for a *specific* snapshot, the per-booking extrema are jointly attained — i.e. whether `availability_lower_bound`/`availability_upper_bound` happen to coincide with the exact attainable set — is snapshot-relative and not settled a priori by WHL. Cycle 2 correctly says "check R6's intervening-value condition"; what remains open is whether any particular snapshot satisfies it. That is a question to be carried, per RSS's own "open questions are not solved" stance, and per R6/R7 it should not be closed by assertion.
