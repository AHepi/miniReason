C12 — Adaptive urn after six draws

Givens:
- If red is drawn, return it and add one blue ball.
- Perform six rounds, applying the update before the next draw.
- If green is drawn, return it and add one red ball.
- If blue is drawn, remove it and add one green ball.
- Each round draws one ball uniformly from the current urn.
- Initially the urn has 3 red, 2 blue, and 1 green ball.

Question: Give the most probable final `(red,blue,green)` state and its exact probability. Also give the exact probability that the sixth draw is red.
Work from the prose only. Do not use code or retrieval. If the information is insufficient, say cannot decide and name the missing derivation.
