C06 — Constrained monotone grid paths

Givens:
- Visit exactly one of the checkpoints `P=(3,4)` and `Q=(6,7)`; visiting both is forbidden.
- For lexicographic comparison use `D<R`.
- Do not visit `(2,2),(4,3),(5,6),(7,5),(8,8)`.
- Never take three R moves consecutively and never take three D moves consecutively.
- Start at `(0,0)` and finish at `(9,9)` using only `R:(x,y)->(x+1,y)` and `D:(x,y)->(x,y+1)`.

Question: Give the number of valid paths and the lexicographically first valid move string.
Work from the prose only. Do not use code or retrieval. If the information is insufficient, say cannot decide and name the missing derivation.
