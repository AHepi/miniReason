C09 — Weighted finite transducer

Givens:
- Twelve independent input bits are read; each bit is 1 with probability 3/5 and 0 with probability 2/5.
- State starts at `(s,t)=(1,0)` with s modulo 4 and t modulo 3.
- On input 0 set `(s,t)=(s+t, t+1)` in the respective moduli.
- On input 1 set `(s,t)=(2s+t+1, s+t)` in the respective moduli.
- Both right-hand sides use the pre-input state.

Question: What is the exact joint probability that exactly seven input bits are 1 and the final state is `(2,1)`? Also state how many seven-1 bit strings reach that state.
