# C19 sealed answer

```json
{"problem_id":"C19","identity":"sum_{k=1}^n 1/(k(k+1)(k+2)) = n(n+3)/(4(n+1)(n+2))","domain":"n nonnegative integer"}
```

Use `1/[k(k+1)(k+2)] = (1/2)(1/[k(k+1)]-1/[(k+1)(k+2)])`. The finite sum telescopes to `1/4-1/[2(n+1)(n+2)]`, which simplifies to the stated expression. At n=0 both sides are zero. For k>=1 and n>=0 all displayed integer denominator factors are nonzero.

Trap: dropping the surviving endpoint term gives 1/4. The script checks exact rational instances and a concrete mismatch for that faulty constant; those finite checks are not the universal proof, which is the human telescoping derivation.
