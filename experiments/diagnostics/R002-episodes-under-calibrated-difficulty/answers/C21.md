# C21 sealed answer

```json
{"problem_id":"C21","closed_form":"a_n(x)=sum_{j=0}^{n-1}x^j","at_x_1":"a_n(1)=n"}
```

The formula holds for n=1 and n=2. If it holds for n and n+1, then `(x+1)sum_{j=0}^n x^j - x sum_{j=0}^{n-1}x^j = sum_{j=0}^{n+1}x^j`. Induction proves the polynomial identity, and evaluation at x=1 gives n.

Trap: `(x^n-1)/(x-1)` is only a rational presentation and is undefined at x=1 unless the removable case is handled. The script verifies recurrence coefficient certificates to a declared bound; that is not the universal proof.
