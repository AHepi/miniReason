# C23 sealed answer

```json
{"problem_id":"C23","identity":"sum_{k=0}^n (-1)^k C(n,k)/(k+1)=1/(n+1)"}
```

Since `1/(k+1)=integral_0^1 t^k dt`, the finite sum equals `integral_0^1 sum_k C(n,k)(-t)^k dt = integral_0^1 (1-t)^n dt = 1/(n+1)`. The interchange is automatic for a finite sum.

Trap: applying `sum (-1)^k C(n,k)=0` ignores the varying factor `1/(k+1)`. The script verifies the exact factorial certificate for a range of n; finite checking is not the universal binomial/integral proof.
