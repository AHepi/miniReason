## 2. Memo C's grounds, scope, mistaken assumptions — clause by clause, with clause-defect vs. application-defect marked

I now assess memo C directly rather than only via what cycle 11 or 12 said about it. The statuses I am licensed to use (from R7/R8 and the task): a *valid criticism*, an *invalid one*, a *still-open question*.

### C1 — "rejection of a supporting assumption is a refutation; therefore A's conclusion is established false for every account."

**Grounds offered:** an attributed rule ("our representation calls … a refutation") plus a derived universal conclusion.
**What WHL actually contains (clause check):** `Refutation c : Type := (snap : Snapshot) (not_c : ¬ c snap)` — a counterexample refutation of a specific conjecture. WHL does *not* encode assumption-dependence; its own note says so. So the *rule* C1 attributes to "our representation" is not a WHL clause.
**What RSS actually contains (clause check):** RSS does list three kinds of refutation, including (c) "a demonstration that a conjecture depends on an assumption that another account rejects," but scopes all refutations as "local to accounts" and does not force global agreement.
**Scope / mistaken assumption:** C1 treats a *defeat of a support route* (available) as *proof of falsity of the conclusion for every account* (not available). The mistaken assumption is that rejecting an assumption is *established false* universally.
**Outcome:** C1 as a criticism *of the representation* is **invalid** — it targets a rule no selected text asserts. As a criticism *of a potential individual application* — someone who globalized an assumption-rejection — it would be **valid**, but no such application is supplied and I will not manufacture one. The underlying observation the criticism gestures at (WHL cannot express assumption-dependence) is a **still-open limitation**, correctly catalogued by WHL's own notes.

### C2 — "a local commitment closes global inquiry."

**Grounds offered:** an attributed meta-rule.
**Clause check:** WHL has no inquiry-state primitive; `Commitment : Type := Prop` carries no globalising machinery. RSS explicitly makes commitment "local to an account" and keeps "a set of open questions." R7 explicitly denies the inference from defusing support to proving falsity.
**Scope / mistaken assumption:** the assumption that "the representation" contains a commit-to-close rule. Neither selected text does; RSS's machinery is built to *prevent* exactly this.
**Outcome:** C2 is an **invalid criticism of the representation** (there is no clause to criticize) and, absent a supplied application that actually globalizes, not a criticism of any application here. The residual sound claim — "a commitment is local" — is already RSS's and R7's rule, not memo C's discovery.

### C3 — "every projection must lose information; also on a singleton domain and for injective projections."

**Grounds offered:** RSS's slogan ("projections … always a loss of information").
**Clause check:** the slogan is RSS's wording, not WHL's. R6 in the selected contract *encodes a typed distinction*: exact set vs. bounds, with the rule that an interval must not be equated with an exact set unless all intervening admitted integer values occur. On a singleton domain a projection to the sole answer loses nothing distinguishable; on an injective projection over the admitted domain the map is invertible there.
**Scope / mistaken assumption:** C3 conflates (i) a projection being *lossy in general* with (ii) being *lossy on every admitted domain*, and it misattributes RSS's rhetorical over-broad phrasing as if it were a load-bearing clause. The mistaken assumption is that a slogan with no domain qualification is a formal claim.
**Outcome:** as a *language-clause* criticism it **targets RSS, not WHL**, and even then the clause is a slogan rather than a specification. As an *appraisal rule* ("all projections are lossy, therefore the representation is defective") it is **invalid**. The genuine, usable distinction — R6's typed lossy/non-lossy reporting — is retained.

### C4 — "no conflict-resolution algorithm, therefore the problem is noncomputable."

**Grounds offered:** an omission in a semantic proposal, plus an inference to noncomputability.
**Clause check:** "noncomputable" is a property of functions (no TM computes them on all inputs); "no algorithm supplied" is a property of a *presentation*. These are compatible in both directions. RSS *declares* its noncomputability as a design stance ("It is deliberately noncomputable … it treats any demand for a single answer as a projection that must be justified outside the semantics"), not as a computability result. WHL's per-booking task is finite enumeration over a finite greatest-revision set.
**Scope / mistaken assumption:** the assumption that *presentational omission* entails *mathematical noncomputability*. That is an unwarranted disjunction collapse.
**Outcome:** C4 is an **invalid inference** as a criticism of the representation; it would need either a reduction from a known undecidable problem or a diagonal argument, neither supplied. Even if the general claim were true, it would not reach WHL's finite per-booking enumeration.

### C5 — "existence of a Lean predicate proves faithful capture and adequate application."

**Grounds offered:** an inference from type-existence to semantic authority.
**Clause check:** WHL itself separates types from intended meanings. `exact_duplicate` is a structural conjunction; the file's notes explicitly say the language "does not say that near-duplicates are inert," and it lists assumption-dependence, replication, physical resource sharing, and per-replica logical time as *expressive limitations*. The file says: "The language does not assert which conjectures are true; it provides the vocabulary to state them."
**Scope / mistaken assumption:** the assumption that well-formedness is semantic authority. If adopted as an appraisal rule, it would classify WHL's own declared predicate/intended-meaning gap as an *error* — i.e. it would require WHL to be worse than it is designed to be.
**Outcome:** C5 is an **invalid universal rule**. The sound residual is C6 ("being able to express a false claim is not a defect by itself") plus the WHL design that *encodes* the type/meaning gap as a feature. A predicate's *use* can of course be criticized case-by-case (that is where an application-defect would live), but C5 overreaches by trying to make existence into faithfulness.

### C6 — "expressibility of false claims is not a defect by itself; the question includes what distinctions the representation allows us to inspect, criticize and use."

**Outcome:** **valid and adopted.** This is the memo's own register statement; it articulates the criterion under which C1–C5 were assessed. It also *enacts* itself: memo C states false-sounding clauses and invites assessment, which is a demonstration of C6 rather than a violation of it.

**Summary of statuses (memo C, clause-level vs. application-level):**

| Clause | As criticism of a *language clause* | As criticism of an *application* |
|---|---|---|
| C1 | invalid (targets a rule no selected text asserts; WHL's *lack* is misread as an endorsement) | would be valid *if* an application globalized assumption-rejection; none supplied |
| C2 | invalid (no commit-to-close clause exists) | would be valid *if* an application did this; none supplied |

| C4 | invalid inference | irrelevant to WHL's finite per-booking enumeration |
| C5 | invalid as universal rule | the *right* shape: predicate *applications* can be criticized; predicate *existence* cannot confer authority |
| C6 | n/a (register statement) | valid; the criterion |

The distinction the block demanded is now explicit: C1, C2, C4, C5 are defective *as general criticism of clauses*; C3 has a *clause-level* defect in RSS's slogan but a genuinely *application-level* residual (using bounds as if exact); C6 is the register under which application-level criticism is done.

## 3. Mistaken assumptions shared across memo C — stated plainly

Three assumptions recur and are the source of most defects:

1. **That a slogan or a stated but unendorsed clause is a load-bearing commitment of "the representation."** C2, C3, C5 each assume this. Under WHL the load-bearing commitments are R1–R8 plus the file's own declared vocabulary; a critical clause that the text does not assert is not a defect *of the text*.
2. **That silence on X is endorsement of the negation of X** (C1 essentially relies on this). WHL's silence on assumption-dependence is a *limitation*, not a rule that "rejection = refutation."
3. **That a description of a presentation-omission is a mathematical result** (C4). Presentation and decidability are different properties of different objects.

None of these assumptions is required by memo C's own C6; C6 actually blocks them, because it points to *what distinctions* a representation lets us use, which is what WHL's "intended meaning" and "expressive limitation" notes catalogue.
