## The scope problem, given usable content

The new problem is not a defect in Memo B or in WHL; it is a scope problem inside the earlier account's own results. In earlier cycles (5, 9) I characterised this only as a coupling question to carry forward in prose. Cycle 9 labelled the old results "conditional on R5-independence," and gave that antecedent a *stated resource interface*. Cycle 10 confirms the same treatment applies to case B and to the new problem's content.

What would have to be supplied. Two sorts, kept distinct, because a resource and a methodological condition are not the same thing:

*Resources that would enable investigation of the coupling.*
1. **A coupling rule or resource model** — a stated constraint on which combinations of cross-booking alternatives are admissible (e.g. that selecting W's 6 forbids selecting V's 3, or a global accounting period, or an explicit exclusion between specific quantities of specific bookings). R5 says none has been supplied for this task, and supplying one here would be the manufacture the task forbids.
2. **A way to express cross-booking admissibility within the representation.** WHL, as it stands, has only capacity as a global constraint, and its own notes say cross-booking constraint and physical resource sharing beyond capacity cannot be expressed. Investigating the coupling inside WHL would need an extension (a new relation recording which alternative pairs are excluded, or a resource primitive); otherwise the investigation goes on outside WHL and its results must be imported and flagged, not laundered into the WHL reading.
3. **Data about the actual cross-booking interactions of the intended warehouse.** Without (1) or (2) this is idle.

*Methodological conditions, not resources.*
4. **An explicit refusal to invent a coupling rule in this cycle.** This is a condition on method, not a supplied resource; the earlier sorting of this point stands.
5. **Preservation of the prior result with its named antecedent.** The case-B set {1, 5} and case-A set {−2, 3} are each the exact set *conditional on R5-independence and on no cross-booking admissibility structure having been supplied*. These must be quotable as conditionals; they must not be presented as scope-free answers to "what can this warehouse promise."

What follows. If a coupling rule is later supplied, the earlier independent-choice sets are subsumed as the special case in which the coupling is vacuous. If no coupling rule is supplied, the earlier sets answer only the narrower R5-independence question. That relabeling does not require selecting a coupling rule, and it is the whole of what the current task's second B6 sentence demands.
