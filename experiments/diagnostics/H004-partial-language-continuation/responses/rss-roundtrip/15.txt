## 3. Exact set of availability values for case C (R6)

Availability = capacity − sum of the selected booking reservations, one payload alternative per booking, alternatives of different bookings independently admissible (R5).

- A ∈ {1, 4}; B ∈ {2, 6}; sums = {1+2, 1+6, 4+2, 4+6} = {3, 7, 6, 10}.
- Availability = 3 − sum ∈ {3−3, 3−7, 3−6, 3−10} = **{0, −4, −3, −7}**.

**Exact set of availability values for case C: {0, −3, −4, −7}.** Four values. Negative values are permitted under R6; the sign alone identifies neither a corrupt record nor a physical stock discrepancy.

**Bounds, kept separate (R6).**
- Per-booking reservation ranges: A ∈ [1, 4]; B ∈ [2, 6].
- Global lower bound = capacity − sum of per-booking minima = 3 − (1 + 2) = **0**.
- Global upper bound = capacity − sum of per-booking maxima = 3 − (4 + 6) = **−7**.
- Reported as bounds: **[−7, 0]** (lower bound 0, upper bound −7).

**Discrepancy to expose.** The interval [−7, 0] contains −6, −5, −2, −1 as well as the four admitted values. Those four integers do **not** occur under any admissible combination, so under R6 the interval **must not** be equated with the exact set. The exact set is {0, −3, −4, −7}; [−7, 0] is the correct *bounds report* and the wrong *set report*. The endpoints of the interval are the correct extremes, which is what makes the bounds report usable as bounds and dangerous as a substitute for the set.

## 5. Discrepancies between the original representations and the declared contract

Both cases expose the same contract-versus-representation gaps; case C puts the first one under load.

- **WHL's `expired_deletes_rule` versus R3/R4.** WHL supplies an alternative reading in which expiry *deletes* the record, so a lower revision can become greatest. R3/R4 choose the structural-supersession reading: expiry changes a retained record's effect, not its revision authority. Case A puts them at odds: under the contract, a1 (rev 1, qty 8, exp 20, active at time 10) does not resurrect when a2 expires; under the deletion reading it would. Contract answer A ∈ {0}; deletion reading would give A ∈ {8} or other values. The contract governs by declaration; the deletion reading remains a usable contrast case, not the operative one here.
- **WHL's `reserves_effect` at `t = expiry` versus R4's strict inequality.** R4 says a hold reserves its quantity only when `time < expiry`; WHL's `reserves_effect` uses the non-strict `¬ (t > expiry)`, reserving the quantity at equality. Case A has `time 10`, `expiry 9` (not equality) and case C has `time 0`, `expiry 10` (not equality), so neither case turns on the boundary; the clause-vs-clause tension remains open and carries no force in these two computations. I retain my prior attribution: this is a clause-vs-clause disagreement, the *named-tension* framing is mine, and its residual risk is application-level — using one clause where a different governing reading supplies the other — not a defect in either case's arithmetic here.
- **Label-versus-authority (R1/R2).** Case A's b1 and b1-copy carry *different* delivery labels but identical payloads (they collapse, R2); b2 carries a different payload at the same greatest revision and so is a genuine alternative (R2, R5). If labels conferred weight, b1 + b1-copy would outvote b2 and B would reserve 3 alone, giving availability {3}. The contract's reading gives {3, −2}. Case A separates the two readings by result.
- **Cross-booking constraint (R5).** Case C is where a suppressed cross-booking constraint would bite hardest: knowing capacity 3 and both bookings' high alternatives, one might be tempted to rule out the joint choice (A = 4, B = 6) as exceeding capacity. R5 supplies no such constraint for this task; R6 says availability is capacity minus the *sum*, and negative values are legitimate. So −7 survives as an admitted value: 3 − (4 + 6) = −7. If a cross-booking resource model existed, it would be a primitive to be *added*, and its absence is the reason this value is admitted.
- **Exact set versus interval (R6).** Both cases exhibit the same defect class. Case A: exact {3, −2}, interval [−2, 3], with four intervening integers fabricated by the flattening. Case C: exact {0, −3, −4, −7}, interval [−7, 0], with four intervening integers fabricated by the flattening (−6, −5, −2, −1). Same rule, same defect, two concrete instances.
- **Negative availability (R6).** Both cases produce negatives. They are permitted; they do not by themselves locate a responsible booking. In case C the value −7 arises only from the joint choice A = 4, B = 6; the sign alone does not reveal that the joint choice, not a single booking, is responsible.
- **Specified scope (R5) versus universal claim.** R5 is the declared task scope for the independence of different bookings' alternatives; RSS's analogous note is "Alternative compatibility … invisible unless a viewpoint includes a resource model." The scope is the contract's specified one, not a universal physical claim, and the missing-resource-model question remains open (see §7).
