# Prospective fixed-construction reason-use materials

This directory contains complete proposed input bytes for a successor to E015. No live call has been made from this package. Integration and publication of the experiment plans remain the root operator's job. The exact executable source identity must be frozen after integration, not against the staging overlay.

The immediate question is whether changing a supplemental reason changes a model's commitment-level response to a fixed construction and whether a resulting account is then used in an isolated task. The broader project asks how proposed languages and Mini expand or hinder expression, criticism and use. This probe can illuminate one reason-use route; it cannot by itself establish Mini's advantage, historical novelty or creativity.

The input files already use the staging runner's `freeze_occurrence` format. The `inputs-original.json`, `inputs-recoded.json`, `inputs-different.json` and `inputs-omitted.json` files each contain exactly the six required occurrences. The root operator can call `make_plan` on these objects once the code is integrated. Select present or empty account using the plan's `return_path` field; do not edit stimulus bytes to implement the control. The omitted supplemental criticism is an exact zero-byte file.

The common source is a JSON text envelope. Its `e004_packet.packet_json_text` field retains the original E004 packet file's exact UTF-8 text, including its escaped language strings, rather than silently normalizing them. The full selected E009 criticism and exact P7/P9 occurrences and question are attributed separately. The adjacent raw common files allow byte comparison without a chat transcript.

The use route deliberately differs from the first candidate design: it receives only the frozen use-domain data, questions and the produced account, or the same empty account field under the no-return control. It receives no independent C0, packet, J, R or accumulated episode history. Material quoted in the exact produced account is intentionally retained and attributed to that return route.

Only the six selected occurrences and frozen stage/system instructions should enter model requests. Do not provide this README, receipts, interpretation, correspondence review, exposure audit, condition name or a bundle of variants as prompt material. File hashes establish custody, not substantive equivalence or reason use.

The only E015 response contents inspected in selecting these materials were J and R. Previously published review/status documents were read for recovery and purpose; no E015 revision or promotion response file was read. These are deliberately selected observed objects, not independently sampled discoveries. The numerical task is prospective and operator-authored.

No repository files were edited during package preparation. Root integration should preserve this complete directory as a new materials version, publish the decision receipts, verify the actual integrated request renderer and freeze separate experiment plans.
