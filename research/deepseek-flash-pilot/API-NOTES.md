Read on 2026-09-17 UTC. Only official DeepSeek API documentation was consulted externally. Documentation claims describe the service on this date, not historical model-weight identity or measured reliability. Transient timeouts on slashless guide URLs were resolved using canonical trailing-slash URLs; the obsolete function_calling URL rendered the quick start, so the actual tool_calls guide is cited instead.

| Feature | Official documentation | Repository consequence |
|---|---|---|
| Model, capacity, prices | [Models and pricing](https://api-docs.deepseek.com/quick_start/pricing/): `deepseek-flash` serves DeepSeek-V4.1-Flash; retired `deepseek-v4-flash` and `deepseek-v4-flash-vision-exp` aliases also serve it. Context 1M; output up to 384K. Per million tokens, peak USD input cache hit 0.006 / miss 0.30 / output 1.20; off-peak 0.003 / 0.15 / 0.60. Peak weekdays 01:00-04:00 and 06:00-10:00 UTC. | Endpoint registry lines 5-13 sends the official Flash ID to `https://api.deepseek.com/v1/chat/completions`; local concurrency is five, timeout 180 seconds. Do not reinterpret earlier returned aliases as a pinned weight version. |
| Thinking | [Thinking guide](https://api-docs.deepseek.com/guides/thinking_mode/): explicit `thinking.type` enabled/disabled; default enabled/high. Effort low/high/max; medium maps to high. Thinking ignores temperature and presence/frequency penalties. Tool-bearing follow-ups must replay all prior reasoning content; ordinary no-tools turns do not need it. | `provider_openai_compat.py:534` sends the toggle, `:536` sends enabled effort. Its validator at `:467` only admits low/high/max; reason CLI has a compatibility adapter for medium. Use disabled control/tool turns and isolated no-tools thinking leaves to preserve the no-hidden-reasoning-storage rule. |
| JSON objects | [JSON output](https://api-docs.deepseek.com/guides/json_mode/): use `response_format.type=json_object`, request JSON explicitly and show an example; truncation and occasional empty content remain possible. | Builder `:523` forwards response_format; `:549` checks the JSON prompt. JSON syntax is not role-contract acceptance or answer correctness. |
| Function schema and strict mode | [Tool calls](https://api-docs.deepseek.com/guides/tool_calls/): function name/parameters schema, assistant tool calls and matching tool-result IDs; host executes functions. Beta strict mode uses `/beta` and strict:true on all functions. Every object property must be required and additionalProperties:false; supported primitives include enum, array, anyOf. String length and array size bounds are unsupported, so enforce them locally. | `extra` can carry tools (`:537`), but normalizer `:764` discards tool_calls and `_finish` at `:681` rejects non-stop finish reasons. Existing complete() is not a usable tool-turn transport without a dedicated adapter. |
| Response schema, parallel requests, streaming | [Chat reference](https://api-docs.deepseek.com/api/create-chat-completion/): response_format lists only text/json_object, not json_schema. tool_choice auto/required accepts one or more calls; required/named choices need thinking off. An explicit parallel_tool_calls parameter is NOT FOUND. Streaming uses SSE ending with [DONE], with usage on the last content chunk. | Strict function arguments are the documented schema-constrained probe; free-response json_schema is skipped. Multi-tool emission is probed without an undocumented parallel flag; execution scheduling remains host-owned. Builder `:518` fixes stream:false and `:447` prevents overriding it through extra. |
| Rate limits | [Rate limit and isolation](https://api-docs.deepseek.com/quick_start/rate_limit/): Flash account-level concurrency limit 2500, excess HTTP429; keys share the account quota. Requests occupy a slot until completion. A fixed requests-per-minute or tokens-per-minute allowance is NOT FOUND on this page. | Keep the stricter repository five-call cap; do not infer a throughput guarantee or retry authority from the service concurrency limit. |

The chat reference gives `max_tokens` range 1-393216 and couples input plus generated tokens to the context limit. Its defaults are 8192 non-thinking, 65536 thinking, or 131072 at max effort. All probes set explicit ceilings. The API notes above are documentation findings; tool reliability, safe stopping and routing competence remain unmeasured until the prepared probes execute.
